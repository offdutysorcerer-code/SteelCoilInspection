# 標註指南

## 目標

先建立可訓練 YOLO 的物件偵測資料集。第一版不用追求完美，重點是規則一致。

## 類別定義

### 0. coil
鋼捲本體。框住整個可見鋼捲，不需要包含拖車平台或木座。

### 1. coil_id_text
鋼捲上的可讀編號區域，例如粉筆字、噴字、手寫編號。只框文字區域，不要框整個鋼捲。

### 4. strap
固定鋼捲的鐵帶、綁帶或束帶。若很細，仍用窄框標記整段可見區域。

### 3. chain
固定鏈條。只框可見鏈條本體。

### 4. rubber_pad
黑色橡膠墊、防滑墊、墊片。若一片橡膠墊分成多段可見，能判斷同一片時可框整片；遮擋嚴重時分開框。

### 5. wood_block
鋼捲下方木座、木枕、墊木。只框可見木材區域。

### 6. tarp
防水布、帆布、藍布、棕色覆蓋布。

### 7. trailer
拖車平台。通常只要框主要車斗平台，不必包含輪胎與車頭。

## 標註原則

- 框要盡量貼近物件外緣。
- 被遮擋的物件只框可見部分。
- 同一張圖有多個同類物件就全部標。
- 模糊但肉眼可辨識的物件仍標。
- 不確定的物件先標，並在檔名或備註中記錄，後續複查。

## 工具建議

優先順序：

1. CVAT：適合多人與大型資料集
2. Label Studio：介面彈性高
3. LabelImg：簡單、離線、適合快速開始

標註輸出格式請選 YOLO detection format。
